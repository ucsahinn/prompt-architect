Package d'architecture de prompts pour Codex avec workflows plan-first, gates d'approbation et checklists de sécurité pour un développement assisté par IA vérifiable.

## Objectif

- transformer des demandes de code vagues en prompts Codex vérifiables
- séparer planification, exécution, règles d'arrêt et vérification
- relier Prompt Lab, skills, subagents, QA navigateur et gates de release
- maintenir des dépôts publics sans secrets, prompts privés ni chemins locaux
