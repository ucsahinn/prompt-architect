# Command Cookbook

Short commands the user can paste into Prompt Lab.

## Codex

```text
Codex goal + full prompt: [task]
```

```text
Create a Codex plan-only prompt for: [task]
```

```text
Create a Codex execute-after-approval prompt for: [task]. Approval phrase: APPROVED.
```

```text
Create a direct Codex execution prompt for this bounded task: [task]
```

```text
Create a Codex Goal + Full Prompt pair. Context: [context]. Must not: [constraints].
```

```text
Codex için goal + full prompt üret: [görev]
```

```text
Goal kullanmadan plan-only Codex promptu üret: [görev]
```

```text
Codex erken execute etmesin diye promptu sertleştir: [prompt]
```

```text
Codex başladıysa durdurma/recover promptu üret: [durum]
```

```text
Bu Codex promptunu scope creep'e karşı güçlendir: [prompt]
```

```text
Bu Codex promptuna browser QA ekle: [prompt]
```

```text
Bu Codex promptuna security constraints ekle: [prompt]
```

```text
Bu Codex promptunu test et ve skorla: [prompt]
```

```text
Bu Codex promptu için approval execute promptu üret: [plan/prompt]
```

```text
Bu dağınık talimatları Codex enterprise promptuna çevir, yorum yapma: [talimatlar]
```

```text
Codex için STOP / RECOVER promptu üret. Codex plan-only iken edit yapmaya başladı: [detay]
```

```text
Codex için large app cleanup + browser QA + security gated prompt üret: [app context]
```
