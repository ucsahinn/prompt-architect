Paquete de arquitectura de prompts para Codex con workflows plan-first, gates de aprobación y checklists de seguridad para desarrollo asistido por IA que sea revisable.

## Propósito

- convertir solicitudes vagas de código en prompts de Codex verificables
- separar planificación, ejecución, reglas de parada y verificación
- unir Prompt Lab, skills, subagents, QA en navegador y gates de release
- mantener repos públicos sin secretos, prompts privados ni rutas locales
