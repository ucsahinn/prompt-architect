Pacote de arquitetura de prompts para Codex com workflows plan-first, gates de aprovação e checklists de segurança para desenvolvimento assistido por IA que possa ser revisado.

## Propósito

- transformar pedidos vagos de código em prompts verificáveis para Codex
- separar planejamento, execução, regras de parada e verificação
- conectar Prompt Lab, skills, subagents, QA de navegador e gates de release
- manter repositórios públicos sem segredos, prompts privados ou caminhos locais
