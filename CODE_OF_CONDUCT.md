# Code of Conduct

## Our Pledge

We want this project to be a practical, respectful space for improving Codex prompt engineering and AI coding-agent workflows.

Participants are expected to communicate professionally, assume good faith, and focus on concrete improvements.

## Expected Behavior

- Be respectful and constructive.
- Keep feedback specific and actionable.
- Prioritize safety, clarity, and source-backed guidance.
- Avoid adding private data, secrets, or unrelated content.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information or secrets.
- Submitting malicious prompt patterns or unsafe instructions as legitimate guidance.
- Repeatedly derailing project scope.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior harms the project or community.

## Scope

This code of conduct applies to project issues, pull requests, discussions, documentation, and other project spaces.
